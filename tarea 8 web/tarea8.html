Tipos de estilos en CSS

Estilos de Linea

Estos estilos se vana agregar directamente en el elemento html, mediante el atributo STYLE

Este parrafo tiene estilos de linea

Estilos internos

Estos estilos se agregan en el mismo archivo html, dentro de la etiqueta <head> y para agregarlos se utiliza el elemento: <style>

Estilos externos

Estos estilos son los que se recomiendan utlizar, ya que permite modularidad, fácil mantenimineto, orden, eficiencia entre otras ventajas, para agregar una hoja de estilos externos dentro la etiqueta <head> se utliza el elemento <link>, donde se especifica la ruta de nuestra hoja de estilos
